Layer 3 Switching

Inter-VLAN SVI Routing

Configured Switched Virtual Interfaces (SVIs) on a Cisco Catalyst 3650 Multilayer switch to handle wire-speed packet routing between subnets without bottlenecking the Core Router.

Domain Isolation

VLAN Segmentation

Logically segmented enterprise network into Students (VLAN 10), Faculty (VLAN 20), and Administration (VLAN 30) to restrict broadcast storms and eliminate eavesdropping risks.

Inspect VLAN Matrix →
IEEE 802.1Q

Trunking & Encapsulation

Established 802.1Q trunk links across Gigabit Ethernet switch ports between Access Switches and the Distribution Switch, enabling seamless multi-VLAN frame transport.
