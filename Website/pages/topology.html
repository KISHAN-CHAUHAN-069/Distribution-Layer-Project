Cisco IOS Configuration Scripts

Actual CLI command blocks configured in Cisco Packet Tracer switches.

Cisco-Packet-Tracer/configurations/routing-config.txt

1. Layer 3 Distribution Switch SVI Routing

SW-DIST-01 Configuration (Layer 3 Switch)
enable configure terminal hostname SW-DIST-01 ! Enable Layer 3 Routing ip routing ! Configure Switched Virtual Interfaces (SVIs) interface Vlan10 description Students Default Gateway ip address 192.168.10.1 255.255.255.0 no shutdown exit interface Vlan20 description Faculty Default Gateway ip address 192.168.20.1 255.255.255.0 no shutdown exit interface Vlan30 description Administration Default Gateway ip address 192.168.30.1 255.255.255.0 no shutdown exit
Cisco-Packet-Tracer/configurations/trunk-config.txt

2. IEEE 802.1Q Switchport Trunking

Trunk Link Configuration (SW-ACCESS-01 & SW-DIST-01)
interface GigabitEthernet 0/1 switchport trunk encapsulation dot1q switchport mode trunk switchport trunk allowed vlan 10,20,30 description 802.1Q Uplink to Distribution Switch no shutdown exit
Cisco-Packet-Tracer/configurations/vlan-config.txt

3. Access Switch VLAN & Switchport Assignment

Access Switch Configuration (SW-ACCESS-01)
