Project Motivation & Objectives

Detailed breakdown of problem statement and architectural scope.

⚠️ Problem Statement & Network Bottlenecks

In traditional flat enterprise network topologies, all workstations (students, faculty, and administration) reside within a single broadcast domain. This unsegmented architecture introduces severe technical issues:

  • Broadcast Storms: High volume ARP, DHCP, and discovery traffic floods every switch port, degrading network speed.
  • Security & Eavesdropping Risks: Students can easily intercept unencrypted administrative traffic or launch ARP spoofing attacks.
  • Routing Overhead: Connecting Access Switches directly to a single Core Router creates severe processing bottlenecks on the central gateway.

The Solution: Deploying a dedicated Distribution Layer equipped with a Layer 3 Multilayer Switch to enforce logical VLAN segmentation, perform wire-speed Inter-VLAN routing, and apply centralized security policies.

🎯 Core Project Objectives

  • Construct a 3-tier hierarchical enterprise network in Cisco Packet Tracer.
  • Configure VLAN 10 (Students), VLAN 20 (Faculty), and VLAN 30 (Admin).
  • Implement 802.1Q trunk links across switch interconnections.
  • Deploy Switched Virtual Interfaces (SVIs) for Inter-VLAN routing.
  • Develop standard/extended Access Control Lists (ACLs) for access control.

💡 Technical Motivation

Understanding the Distribution Layer is essential for modern network engineers. It acts as the intelligent boundary between the high-speed unthrottled Core Layer and the user-facing Access Layer.

Distribution Layer Focus:

Policy control, security boundaries, address aggregation, and QoS enforcement occur here.
