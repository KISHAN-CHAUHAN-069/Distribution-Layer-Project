Hierarchical Layer Breakdown

Exploring the specific responsibilities of each network tier.

Core Layer High-Speed Backbone

Core Layer Router (Cisco 4331 ISR)

Responsible for transport speed and reliability. Executes zero packet-filtering overhead to ensure maximum throughput between campus buildings, enterprise data centers, and external ISP internet connections.

★ MAIN FOCUS Distribution Layer

Multilayer L3 Switch (Cisco Catalyst 3650)

The intelligence boundary of the enterprise network. It interconnects Access Switches to the Core Layer and performs:

  • Wire-Speed Inter-VLAN Routing: Uses Switched Virtual Interfaces (SVIs) for fast hardware packet forwarding between VLAN 10, 20, and 30.
  • Security Policy Enforcement: Centralized Access Control Lists (ACLs) filter malicious or unauthorized inter-department traffic.
  • Broadcast Domain Demarcation: Prevents Layer 2 loops and ARP broadcast storms from leaking into the core backbone.
Access Layer End-User Switchport

Access Switches (Cisco Catalyst 2960)

Provides port connectivity for end devices. Enforces Port Security, assigns switchports to VLANs (`switchport access vlan X`), and connects upstream via IEEE 802.1Q trunks.

End Devices Segmented Hosts

User Computers, Laptops & Admin Servers

Endpoints partitioned logically into VLAN 10 (Students), VLAN 20 (Faculty), and VLAN 30 (Administration Servers).

⚙️ How Switched Virtual Interfaces (SVIs) Work at the Distribution Layer

Instead of routing packets out of physical router interfaces (Router-on-a-Stick), a Multilayer Switch creates virtual Layer 3 interfaces tied to each VLAN ID.

Cisco Catalyst 3650 - SVI Inter-VLAN Routing Script
SW-DIST-01(config)# ip routing SW-DIST-01(config)# interface Vlan10 SW-DIST-01(config-if)# description Gateway for Students Subnet SW-DIST-01(config-if)# ip address 192.168.10.1 255.255.255.0 SW-DIST-01(config-if)# no shutdown SW-DIST-01(config-if)# exit SW-DIST-01(config)# interface Vlan20 SW-DIST-01(config-if)# description Gateway for Faculty Subnet SW-DIST-01(config-if)# ip address 192.168.20.1 255.255.255.0 SW-DIST-01(config-if)# no shutdown
